# FarmMotion 0.4.0 beta candidate

Includes telemetry mod 1.0.0.2. Download the Windows app ZIP and mod ZIP. Extract the app and run FarmMotionUI.exe. Put the unopened mod ZIP in the FS25 mods folder with the game closed.

- Gentler defaults: 10% strength, 0.25x sensitivity, 10% bumps/body and 100% fine texture.
- Adjustable movement response curve, sensitivity down to 0.01x, and a separate fine-texture ceiling.
- Road tire buzz adjusts in 0.01% increments.
- Restart detection lets the mod reopen telemetry after the app restarts, without relying on pipe write errors.

Validated: 156 hardware-free app checks, 22 simulated Lua checks, compact WPF UI checks, and all 15 GIANTS TestRunner modules. No new physical-device testing was performed for this candidate.

Before public release: confirm app restart recovery with FS25 left running, confirm feedback feel, and resolve or accept historical username/path exposure in old TestRunner reports. Controller compatibility and multiplayer remain unverified. Unsigned Windows x64 build; .NET Framework 4.8 required. Not ModHub approved.
