# FarmMotion 0.4.1 beta

One executable to launch: **FarmMotion.exe**. The developer diagnostic console is no longer in the user download. Includes the 0.4.0 feedback and reconnect improvements and telemetry mod 1.0.0.2.

**One-time manual update:** close the old app, extract this app ZIP into a fresh folder, and run FarmMotion.exe. Older in-app updaters require two executables and cannot install this package. Settings carry over; update shortcuts and toggle Start with Windows off/on in the new app if previously enabled. Install the bundled mod with FS25 closed if upgrading from an older mod.

Future updates support the new layout. Hardware and reconnect live-validation limitations from 0.4.0 still apply.
