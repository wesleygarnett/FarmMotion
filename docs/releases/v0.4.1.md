# FarmMotion 0.4.1 public beta

Ever wish farm simulator had force feedback on steering wheels? This mod fixes that. Feel every bump in the road and field, and customize how strong you want to feel it.

## Download and install

1. Download **FarmMotion-v0.4.1-win-x64.zip** and **FS25_FarmMotionTelemetry.zip** below.
2. Extract the Windows app ZIP into a folder and run **FarmMotion.exe**. Keep its supporting files together.
3. With FS25 closed, copy the mod ZIP into Documents/My Games/FarmingSimulator2025/mods. **Do not extract the mod ZIP.**
4. Start FS25, enable FarmMotion Telemetry for your save, then choose your wheel/controller in the app.

Windows x64 and .NET Framework 4.8 required. Includes telemetry mod **1.0.0.2**. The source ZIP is for developers; SHA256SUMS.txt verifies the downloads.

## What's new

- One app executable, FarmMotion.exe, removes the UI/console launch confusion.
- Gentle defaults: 10% wheel strength, 0.25x sensitivity, 10% bumps/body and 100% fine texture.
- Adjustable movement response curve keeps average movement gentle while allowing strong impacts; fine texture has its own limit.
- Road tire buzz adjusts in 0.01% increments.
- App restart detection reconnects telemetry without depending on pipe error returns.

## Updating an older installation

Close the old app and extract this release into a **fresh folder**. Older in-app updaters expect two executables, so this release requires a one-time manual download. Saved settings carry over. Update shortcuts and toggle Start with Windows off/on in the new app if previously enabled. Future updates support the new layout.

## Beta status

MOZA R3 wheel feedback has been tested during development. Other wheels, controller models, USB/Bluetooth combinations and multiplayer need beta testing. Controller output uses ordinary rumble, without adaptive triggers or advanced haptics. Live confirmation of reconnecting after an app restart with FS25 still running remains outstanding. Custom profile paths may require FARMMOTION_FS25_PROFILE; see the user guide.

156 app checks, 22 simulated Lua checks, compact UI checks and all 15 GIANTS TestRunner modules passed. These do not replace physical-device testing. The app is unsigned and this is not a ModHub-approved release.

Please report your app/mod versions, wheel/controller model, connection type and steps to reproduce using the repository's bug-report form. Remove personal information from log excerpts.
