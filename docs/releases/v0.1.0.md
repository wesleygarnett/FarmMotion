# FarmMotion 0.1.0 — Windows preview

**Force feedback & rumble for Farm Simulator**

First portable release for Windows x64 and Farming Simulator 25 single-player. Designed and tried with the MOZA R3; other DirectInput force-feedback wheels are not yet verified.

## Install

1. Download and extract `FarmMotion-v0.1.0-win-x64.zip` to a writable folder.
2. Copy the included `FS25_FarmMotionTelemetry.zip` into your FS25 `mods` folder without extracting that inner ZIP, and enable the mod for your save.
3. Launch `FarmMotionUI.exe`, select your wheel, then start the game. Output starts off. Enable it when ready, beginning at low strength.

Requires .NET Framework 4.8. Keep the `.exe.config` files with their executables for crisp per-monitor scaling. No installer, SimHub or proprietary wheel SDK is required.

## Included

- Suspension/body movement feedback, fine texture and optional road tyre buzz.
- Basic strength/sensitivity controls; Advanced controls and individual help popups.
- High-DPI dashboard, FM icon, recording/replay and original/V1/V2 comparison modes.
- Hardened local telemetry access, bounded inputs, atomic settings writes and asynchronous recording.
- SHA-256 checksums, source archive, GPL-2.0-only license and upstream attribution.

## Preview limitations

- The companion synthesizes movement-based force feedback; this is not TrueForce or a full steering-rack simulation.
- High-frequency rumble depends on actual Windows/driver update cadence. Software carrier tests do not prove physical 50–90 Hz reproduction.
- If restarting the companion during a game leaves packets at zero, leave the app open and save/restart FS25. Recovery has not been fully validated.
- Lua pipe writes are synchronous; stalled storage/reader or OS scheduling can affect the game.
- Binaries are unsigned. This private preview has no auto-update service.

The mod remains version **0.2.0.0**; the companion version is **0.1.0**. Existing tuning settings are retained.
